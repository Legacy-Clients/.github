# 🕰️ Legacy Client

Legacy Client is a **launcher profile** for old Minecraft versions. It pins **libraries**, isolates **instances**, and keeps **per-version Java** so legacy packs still start.

## 🚀 Why Choose Legacy Client?

Old versions break when a modern launcher resolves libraries by itself. Pinning keeps the known-good set, and per-version Java avoids the runtime mismatch.

Instances stay separate, so a legacy pack does not touch a current world.

## 🧩 Quick Start
